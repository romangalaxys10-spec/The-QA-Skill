## Compatibility guarantees

1. **Semantic versioning** across all published packages (`@the-qa-skill/*`). Breaking changes only at major versions; deprecation notices one minor ahead.
2. **Skill format stability:** `skills/*/SKILL.md` sections are a documented contract (see `skills/qa-enterprise/SKILL.md`); additive section changes ship at minor versions.
3. **CLI surface stability:** all 16 commands accept `--json` (machine-readable, schema-versioned output) — automation should target `--json` + `schemaVersion` field.
4. **MCP tools stability:** tool names and Zod-validated input/output schemas are semver'd; new tools are additive.
5. **No silent behavior mutation:** the learning loop records what changed and why; upgrades never change triage/healing decisions retroactively.
